# ADR 006 — Linguagem visual do Centro de Comando

## Status

Aceito em 22/08/2026.

## Direção escolhida

**Centro de operações contemporâneo institucional.** A interface deve parecer uma ferramenta interna construída para supervisores da CHOQUE - BGR, não um dashboard SaaS tematizado.

## Princípios

- Hierarquia por linhas, numeração, contraste e densidade; não por dezenas de cards.
- Olive significa identidade/operacional; âmbar significa atenção; vermelho queimado significa bloqueio/risco; cinza significa inatividade.
- Títulos condensados e técnicos; corpo altamente legível; monoespaçada somente para IDs e horários.
- Sidebar sólida, radius baixo, sombras mínimas e microinterações de 120–220 ms.
- Tabelas e listas são a superfície principal de dados.
- Elemento memorável: a **faixa de situação operacional**, uma linha contínua segmentada que resume o estado do quartel e reaparece como linguagem de navegação.
- Sem camuflagem, armas, caveiras, neon, glassmorphism, gradientes decorativos ou HUD de jogo.

## Acessibilidade

Contraste AA, foco sempre visível, navegação por teclado, estados acompanhados de texto/símbolo e adaptação real das tabelas para telas pequenas.
