# PADRÃO VISUAL OBRIGATÓRIO

O responsável pela criação do servidor deve manter:

```text
EMOJI・𝑁𝑜𝑚𝑒 𝑑𝑜 𝐶𝑎𝑛𝑎𝑙
```

Exemplo:

```text
🚓・𝑃𝑎𝑡𝑟𝑢𝑙ℎ𝑎 1
📣・𝐴𝑣𝑖𝑠𝑜𝑠
👑・𝐻𝑖𝑒𝑟𝑎𝑟𝑞𝑢𝑖𝑎
📋・𝑆𝑜𝑙𝑖𝑐𝑖𝑡𝑎𝑟 𝐶𝑢𝑟𝑠𝑜
```

Não utilizar:

```text
patrulha-1
solicitar-curso
chat-choque
```

A estrutura deverá seguir visualmente o padrão das referências, mas adaptada para a identidade **CHOQUE - BGR**.
